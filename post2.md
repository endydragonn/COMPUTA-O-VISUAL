# Por que usamos RGB para representar cores?

Um ponto que achei interessante sobre **Computação Visual** foi entender o por que computadores, telas e imagens digitais utilizam principalmente o modelo **RGB (Red, Green e Blue)** para representação de cores.

Antes, eu imaginava que o RGB fosse apenas uma escolha técnica para facilitar a representação das cores no computador. Porém, isso tem uma relação com a própria **visão humana**. Nosso olho possui três tipos principais de células chamadas **cones**, que respondem de maneiras diferentes à luz em diferentes faixas do espectro. O sistema visual utiliza essas informações para construir a nossa percepção das cores. É por isso que podemos representar uma grande quantidade de cores utilizando combinações de vermelho, verde e azul. Em uma tela, por exemplo, cada pixel pode controlar a intensidade desses três componentes para produzir diferentes cores.

Isso demonstra uma relação importante entre **Computação Visual e percepção humana**, o computador não precisa representar exatamente todo o espectro de luz para produzir uma determinada cor. Ele pode utilizar uma representação que se aproveita da forma como nosso sistema visual percebe a luz.
